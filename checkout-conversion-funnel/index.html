Business Problem

Every consumer lending decision involves a fundamental tradeoff: approve too few borrowers and you leave revenue on the table; approve too many and default losses erode profitability. This project builds a binary classification model to estimate the probability that a borrower will fail to repay — and frames the output as a business decision tool, not just a technical exercise.
The central question is not "can we predict default?" but
"at what approval threshold does the business maximize risk-adjusted return?"

Methods

EDA
Class imbalance analysis, missing value strategy, distribution plots, default rate by age group
Feature Engineering
Age-group imputation for income, delinquency severity score, debt-per-credit-line, income-to-debt ratio
Modeling
Logistic Regression, Decision Tree, Random Forest with class-weight balancing and probability calibration
Evaluation
ROC-AUC, Precision-Recall curve, calibration curve — not accuracy (misleading for imbalanced data)
Business Threshold
Sweep across decision thresholds — approval rate vs. default rate vs. expected net value per scenario
Fair Lending
Default rate parity and approval rate disparity by age group — proxy for ECOA compliance review

⚖ Fair Lending Analysis

Default rate parity and approval rate were computed across age groups at each threshold. Groups with approval rates more than 10pp below the mean are flagged for regulatory review — mirroring ECOA compliance monitoring in production consumer lending systems.

SQL

Production-quality queries written to mirror how an R&A team monitors a live lending portfolio.

portfolio_risk_summary.sql
-- Aggregate borrower risk metrics by tier to support portfolio monitoring

WITH risk_tiers AS (
    SELECT
        borrower_id,
        predicted_default_proba,
        actual_default,
        loan_amount,
        CASE
            WHEN predicted_default_proba < 0.10 THEN 'Tier 1 — Low Risk'
            WHEN predicted_default_proba < 0.15 THEN 'Tier 2 — Moderate Risk'
            WHEN predicted_default_proba < 0.20 THEN 'Tier 3 — Elevated Risk'
            ELSE                                    'Tier 4 — High Risk (Declined)'
        END AS risk_tier,
        CASE WHEN predicted_default_proba < 0.15 THEN 1 ELSE 0 END AS approved
    FROM borrower_predictions
),

portfolio_summary AS (
    SELECT
        risk_tier,
        COUNT(*)                                        AS total_applicants,
        SUM(approved)                                   AS approved_count,
        ROUND(AVG(approved) * 100, 1)                   AS approval_rate_pct,
        ROUND(AVG(CASE WHEN approved = 1
                       THEN actual_default END) * 100, 1) AS default_rate_pct,
        SUM(CASE WHEN approved = 1
                 THEN loan_amount END)                  AS total_approved_volume
    FROM risk_tiers
    GROUP BY risk_tier
)

SELECT *, ROUND(estimated_loss_exposure / total_approved_volume * 100, 1) AS loss_rate_pct
FROM portfolio_summary
ORDER BY risk_tier;
