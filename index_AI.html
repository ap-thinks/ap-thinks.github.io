My AI philosophy

AI is most valuable when it handles the predictable so I can focus on the unpredictable. Here's how that division plays out in practice.

  • AIGenerates SQL from natural language; I review for silent record drops, wrong joins, and edge case assumptions
  • AIPrototypes Python and R code for analysis; I validate logic, model choice, and output interpretation
  • AIDrafts first-pass summaries of findings; I rewrite for accuracy, nuance, and appropriate uncertainty
  • HumanFrames the question: what are we actually trying to learn, and is this the right way to measure it?
  • HumanInterprets results in context: what does this coefficient mean for this product decision?
  • HumanMakes the recommendation, with conviction, stated uncertainty, and willingness to update

"The most consequential output from an AI is one that looks completely correct and is subtly wrong. That's why I see my role as the final judgment layer: reading AI-generated SQL and code carefully to ensure the output is not just functional, but analytically sound."

Project 01 Consumer Behavior EDA + Python Simulated Data

Does seeing a retention ad make you look more?

A two-phase analysis: first, using exploratory data analysis to segment consumers by search behavior and understand who they are before modeling; then, using OLS regression to quantify how retention advertising is associated with deeper product search intensity. Data are session-level, with multiple sessions per user and Shannon entropy computed from the car body types viewed in each session.

Variable definitions: session-level data

Each row in the dataset represents one unique consumer viewing session on an automotive marketplace. One user can have multiple sessions. The unit of analysis is the session.

Variable Type Role Definition
session_id Integer Identifier Unique identifier for each viewing session.
user_id Integer Identifier Unique identifier for each consumer. One user may have multiple sessions across time.
number_of_pages_viewed Integer Outcome Number of product pages viewed within the session, a proxy for search intensity. Higher values indicate deeper product exploration.
viewable_retention Binary (0/1) Predictor 1 if the consumer was exposed to a retention ad, an ad that targets consumers who are already actively considering the product; 0 otherwise.
entropy Continuous Control Shannon entropy calculated from the car body types viewed in the session (sedan, van, SUV, hatchback, truck, sports). Entropy = 0 when only one body type is viewed (focused search); entropy increases as the consumer views more body types equally (broader, less focused search).
prior_pages_viewed Integer Control Cumulative number of product pages this user viewed across all prior sessions. Captures prior familiarity and baseline interest level.
search_segment Categorical EDA Output Consumer segment derived from exploratory analysis: Focused or Broad, based on entropy and pages viewed per session.
● Phase 1 — Exploratory Data Analysis

Understanding who the consumers are before modeling how ads affect them

Before running any regression, I used exploratory data analysis to segment consumers by search behavior. The goal was to understand the behavioral profiles in the data, check whether ad exposure varied across segments, and identify which control variables the regression would need. This step shapes the model before a single coefficient is estimated.

# Behavioral segmentation: Focused vs. Broad consumers # NOTE: Simulated data, for illustrative purposes only # Segment on entropy (search breadth) at the user level # Low entropy = focused on fewer body types = Focused consumer # High entropy = exploring many body types = Broad consumer import pandas as pd df = pd.read_csv('simulated_sessions_v2.csv') # Aggregate to user level user_profile = df.groupby('user_id').agg( avg_pages = ('number_of_pages_viewed', 'mean'), avg_entropy = ('entropy', 'mean'), avg_prior_pages = ('prior_pages_viewed', 'mean'), retention_ad_rate= ('viewable_retention', 'mean') ).reset_index() # Segment by entropy at the median # Human judgment: median split confirmed against distribution entropy_median = user_profile['avg_entropy'].median() user_profile['search_segment'] = user_profile['avg_entropy'].apply( lambda x: 'Focused' if x <= entropy_median else 'Broad' ) # Summary by segment summary = user_profile.groupby('search_segment')[[ 'avg_pages', 'avg_entropy', 'avg_prior_pages', 'retention_ad_rate' ]].mean().round(2) print(summary)

◆
EDA insight that shaped the regression
The segment profiles confirm a meaningful behavioral divide. Focused consumers view more pages per session and have a 47% retention ad exposure rate, more than double the 22% rate for Broad consumers. This pattern suggests that consumers who are already deep in their search journey are more likely to be shown retention ads, and also tend to view more pages regardless of ad exposure. Without controlling for entropy and prior_pages_viewed, the regression would likely attribute this pre-existing engagement to the ad effect. The EDA makes the case for both controls before a single model is run.
● Phase 2 — Statistical Analysis

Quantifying the effect of retention advertising on search intensity

With the behavioral segments identified and the confounds established in the EDA, the OLS regression quantifies how retention ad exposure is associated with search intensity, controlling for prior product familiarity and search breadth.

Model specification

OLS is used here because coefficients are directly interpretable as the change in pages viewed associated with each predictor, making the results easy to communicate without any additional transformation.

number_of_pages_viewed = β₀ + β₁·viewable_retention + β₂·entropy + β₃·prior_pages_viewed + ε OLS: search intensity · controls for entropy (search breadth) and prior_pages_viewed (prior familiarity)

Python — OLS Regression (statsmodels) AI-prototyped, human-corrected
# OLS: Effect of retention ad exposure on search intensity # Outcome: number_of_pages_viewed (integer count, min 1) # NOTE: Simulated data, for illustrative purposes only # Data: session-level analysis, one user may have multiple sessions # entropy: Shannon entropy from car body types viewed per session # (sedan, van, suv, hatchback, truck, sports) import pandas as pd import statsmodels.api as sm df = pd.read_csv('simulated_sessions_v2.csv') # viewable_retention: key predictor of interest # entropy: Shannon entropy control (broader search = higher entropy) # prior_pages_viewed: cumulative prior pages viewed by this user (integer) predictors = ['viewable_retention', 'entropy', 'prior_pages_viewed'] X = sm.add_constant(df[predictors]) y = df['number_of_pages_viewed'] model = sm.OLS(y, X) results = model.fit(cov_type='HC3') # robust SEs print(results.summary())

Core insight: retention ads are associated with deeper in-session exploration

After controlling for search breadth and prior familiarity, retention ad exposure is positively and significantly associated with search intensity. Consumers shown a retention ad view approximately 0.9 more product pages in the same session on average, suggesting the ad re-engages their attention and deepens their in-session product exploration. The control variables also reveal meaningful patterns: higher entropy (broader search across more vehicle types) is associated with fewer pages viewed per product, consistent with the idea that consumers still exploring broadly spread their attention rather than focusing deeply on any one product. Similarly, higher prior cumulative views are associated with slightly fewer pages in the current session, suggesting that consumers who have already explored a product extensively may browse more selectively on return visits. Both controls are essential for isolating the retention ad effect from pre-existing differences in consumer engagement.
